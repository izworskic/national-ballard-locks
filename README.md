# National Ballard Locks

Authoritative source for the Ballard Locks live visitor intelligence tool served at https://chrisizworski.com/ballard-locks/.

## Product boundary

The tool combines public source signals that help answer whether a Ballard Locks visit is worthwhile now: AIS-equipped vessel traffic, dated WDFW salmon counts, NOAA tide timing, National Weather Service conditions, and U.S. Army Corps of Engineers access, chamber-maintenance, and water-management context.

AIS is a traffic picture, not an official lockage count, and the interface does not claim that every recreational craft is visible.

The production `chrisizworski.com` repository may carry a pinned deployment mirror, but product logic is developed here first.
